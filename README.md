# THE JOINT RESTURANT

Open `index.html` in a browser to use the customer ordering site. Open `admin.html` to add or remove food items and view orders.

This starter stores food and orders in that browser's local storage, so it is ideal for previewing the experience. To accept live customer orders across phones and take online payments, the next step is to connect a hosted database plus a Nigerian payment provider such as Paystack or Flutterwave
